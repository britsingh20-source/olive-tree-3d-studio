## What persists

Customer records and code are committed to GitHub. The private plugin provides reusable instructions and reads those records through available repository tools. It does not itself store conversations, grant GitHub access, convert every SketchUp version, or recover unavailable attachments. If a source is inaccessible, report exactly which file is missing and request only that file.

## Maintenance

Save confirmed decisions and actual verification after every change; do not wait for a chat to reach its limit. Store unresolved questions separately from confirmed decisions. Update plugin source and its saved account release together when workflow instructions change.
