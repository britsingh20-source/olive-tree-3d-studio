# Olive Tree 3D Studio — continuity instructions

Read `docs/STUDIO-WORKFLOW.md` and `customers/index.json` before customer work. For a named customer, read the indexed design record and status file before asking questions or editing a viewer. Start at `CONTINUE.md` when resuming.

User instructions in the active conversation take precedence. Current customer confirmations supersede older records; save the correction immediately. Repository code describes implementation, not proof of customer approval.

Preserve existing architecture, customer routes, source geometry, and visual style. Ask only for missing or ambiguous decisions, one clear question at a time. Show a source colour swatch and ask what it means; avoid unexplained A/B labels. Never guess measurements, internal fittings, rates or commercial terms. Do not transplant another customer's quotation.

After every approved design change or bug fix, update that customer's design/status records in the same change. Record actual validation and limitations; deployment success alone is not visual verification. Keep incomplete work and next actions explicit so another chat can resume.

Do not store credentials, private contact details, home addresses or private quotation documents in this public repository. Store only design information already authorized for this studio. A fresh chat needs repository access and relevant files; do not claim automatic access to old chats or uploads.
